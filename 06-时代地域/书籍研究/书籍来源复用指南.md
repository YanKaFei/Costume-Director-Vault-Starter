## 2. 与 P5-C 新卡主题的映射（建议引用）

- **结构卡**：里布/衬 → SRC-0062（Hand Sewing / Plackets）+ AAT SRC-0540；褶裥/抽褶 → SRC-0062（Dressmaking/Patterns 附近）+ AAT SRC-0543/0544；门襟/扣合 → SRC-0062（Plackets 3167）；领/袖 → SRC-0069（collar/cuff 3598）+ SRC-0062（Collars 4747）；拖尾 → SRC-0064（C22/C23）。
- **材质卡**：羊毛 → SRC-0062（Wool 733）+ SRC-0066（Worsteds/Serge/Flannel/Tweed）+ AAT SRC-0547；亚麻 → SRC-0062（Flax 858）+ AAT SRC-0548；皮革 → 书源弱（仅泛称）→ 以 AAT SRC-0549 + V&A 实物为主；丝绸 → SRC-0062（Silk 1016）+ SRC-0013；合成/涂层 → 书源不覆盖（现代）→ 只用 AAT SRC-0550 + V&A SRC-0406/0417。
- **配饰卡**：领巾/cravat → SRC-0066（3944）；袜/hose → SRC-0066（7819）；帽 → SRC-0069（hats 4097）；鞋 → SRC-0069（5589）+ SRC-0067（622/1185/1190，背景）；珠宝 → SRC-0065（507，背景）+ AAT SRC-0551/0552。
- **不可用**：A/H/Y/T/X 廓形分类、鱼尾摆特殊剪裁、植鞣/铬鞣、具体聚合物（nylon/polyester）——9 本书均无足够具体的定位，相关新卡应标 interpretive 或另补专门来源。

## 3. 已用 / 未用说明

- **已用**：P4-1 的 31 条结论中 **15 条 verified**（书 + 独立来源交叉）可直接作为「书内事实 + 现代佐证」引用；另有 11 条 partial / 5 条 candidate 只能作 book_fact 背景（见 `11-验收/P4-BOOKS/TERMS-GLOSSARY.md`）。
- **未用原因**：① 现有内容卡多已用页面级 SRC（FIT/V&A/Met）承载同类断言，再挂书源会造成重复引用通胀；② 旧书（1847—1919）为二手综述，直接断言风险高；③ 页码不可得（纯文本无可靠页码），只能章/段/行，引用成本高；④ 部分书主题（法国时装史/英国服装/珠宝扇子）与当前 P5-C 结构/材质/配饰卡对应弱。
- **仍缺的文献**：结构工艺（衬/填充/口袋/褶裥）的一手裁剪书/馆藏工艺记录；皮革鞣制工艺；现代合成纤维与涂层技术；纹样（条纹/格纹/印花/刺绣）专门图录；11 世纪苏格兰/中世纪盛期语境；18 世纪法国宫廷服饰。建议后续按 P5 覆盖缺口补专门来源，不要用这 9 本书硬顶。
