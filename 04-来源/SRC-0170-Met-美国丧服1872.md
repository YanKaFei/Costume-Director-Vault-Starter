# SRC-0170 Met 美国丧服 2009.300.673a,b

## 定义
The Metropolitan Museum of Art 藏品 API 的一条对象记录，本卡登记其对象元数据、权利状态与可支撑的事实范围。

## 结构要点
Met Collection API 对象记录包含标题、objectName、年代、文化、材质、尺寸、credit line、isPublicDomain 与 objectURL；本卡以 API 返回值为准。

## 视觉辨识

## 适用条件
