# 人物与视频提示词模板（索引）

本目录提供三份可直接复制的模板，均与 `scripts/recommend.py` 的输出字段同构：

| 模板 | 文件 | 用途 |
|---|---|---|
| 角色设计模板 | [01-角色设计模板](./01-角色设计模板.md) | 输入字段、A/B/C 组装、连续性锁定、严格度措辞 |
| 静态生图模板 | [02-静态生图提示词模板](./02-静态生图提示词模板.md) | 英文生图 prompt 结构公式 + 负向约束 |
| 视频提示词模板 | [03-视频提示词模板](./03-视频提示词模板.md) | 镜头/动作/布料动态/状态切换/多场次连续性 |

## 输入字段

- character_id / scene_id / story_day
- time_period / region / season / weather
- occupation / economic_status / social_context / character_arc
- action / performance_requirements
- art_direction / lighting / camera_distance / budget
- fidelity_mode: historical | inspired | fictional
- tool: midjourney / sdxl / dalle / sora / runway / generic
- state: wetness / damage / dirt / accessory positions（连续性状态）

## 输出结构

1. 已知信息与未证实假设
2. 服装硬约束
3. 候选 Look A/B/C（真实卡片 ID + 衣物明细 + 溯源 + 风险）
4. 推荐理由及权重（年代25 / 身份15 / 环境15 / 美术15 / 动作10 / 弧线10 / 摄影10）
5. 中英文生图 Prompt（全身、正背 3/4、色彩材质、配饰）
6. 英文视频 Prompt（动作、摄影机、材质动态、连续性锁定、镜头不变的属性）
7. 负向约束：禁止衣服变形、突变、凭空增加配饰、无故改变纽扣/颜色/层搭

## 自动填写示例（仅虚构演示）

Character ID: C-INV-001
Look ID: LOOK-EXAMPLE-001
Continuity lock: charcoal knee-length wool coat, off-white stand-collar shirt, straight dark trousers, worn lace-up boots, left-shoulder aged canvas bag.
Motion: coat hem moves with walking and wind; fabric wetness changes only when continuity state explicitly switches.

> 完整可执行流程见 `skills/costume-director/SKILL.md`；真实推荐请运行 `scripts/recommend.py`，不要手写虚构 ID。
