# 角色设计模板（copy-ready）

> 适用：角色造型设计、剧本人物服装方案、生图/视频前置设计。
> 数据来源：只能来自本 Vault 卡片的真实 ID。用法见 `skills/costume-director/SKILL.md`。
> 严格度字段：`historical`（史实依据）/ `inspired`（时代灵感再造）/ `fictional`（虚构，不主张史实）。

## 1. 输入字段（复制后逐项填写）

| 字段 | 必填 | 示例 | 说明 |
|---|---|---|---|
| character / character_name | 是 | 沈砚 | 角色名（真实或虚构需注明） |
| character_note | 否 | 虚构角色 | 真实人物必须另行标注，避免把虚构当史实 |
| occupation | 否 | 报社编辑 | 职业影响服装功能与正式度；不做性格推断 |
| economic_status | 否 | middle / low / high | 经济状态影响材质与磨损程度 |
| period | 是（historical 时） | 1930s | 无把握写 unknown，不写伪精确年代 |
| region | 是 | shanghai / east_asia | 地域/文化 |
| scene / story_day | 否 | 雨夜街口 / Day 2 | 场次与剧情日 |
| weather / season | 否 | rain, autumn | 天气与季节属于硬约束 |
| action | 否 | walking, running, dancing | 动作/表演需求 |
| character_arc | 否 | decline from respectability | 人物弧线；仅作服装变化参考，不是心理诊断 |
| art_direction | 否 | restrained noir | 美术方向；对应 STY 卡 |
| lighting | 否 | cool moonlight + warm practicals | 布光 |
| camera | 否 | medium shot / full body | 景别与镜头 |
| budget | 否 | low / medium / high | 制作预算影响复用与材质 |
| fidelity_mode | 是 | historical / inspired / fictional | 三选一，必须写在输出里 |
| tool | 否 | midjourney / sora / runway / dalle | 生成工具，影响 prompt 后缀 |
| state | 否 | wetness: dry / wet / drying; damage: none | 连续性状态；只在显式切换时改变 |
| negative_exceptions | 否 | 不要帽子的雨夜 | 额外负向约束 |

## 1b. 自由文本输入（P3）

```bash
python3 scripts/recommend.py --brief "1930s Shanghai, a poor journalist in the rain, noir period drama, low budget, historically accurate" --json
```

- `brief_parse` 会输出解析到的 period/region/occupation/economic/weather/art/fidelity/budget；
  缺项保持 `unknown`，不得猜测。
- 输出中的 `warnings_detail` / `conflicts` / 每套 `narrative_meaning` / `evidence_tier`
  要一起交付；不要只复制 A/B/C 单品 ID。

## 2. 执行流程

```bash
# 1) 先检索真实卡片，确认证据与缺口
python3 scripts/query.py "1930s 上海" --type period_region --json
python3 scripts/query.py "大衣" --type garment --style-tag noir --json --limit 5

# 2) 生成 A/B/C 推荐（硬约束 + 100 分软评分）
python3 scripts/recommend.py my-character.json > my-character.md
python3 scripts/recommend.py my-character.json --json > my-character.json.out

# 3) 多场次连续性（同一 Look 锁定）
python3 scripts/recommend.py my-character-scenes.json --continuity > continuity.md
```

## 3. 输出契约（必须包含）

```
角色与剧情理解（区分已知 / 假设）
不可违反的约束
候选造型 A/B/C（Look ID 或 assembled 标记、GAR/STR/MAT ID、颜色、材质、结构、适合原因、风险）
最终推荐 + 解释性评分（年代25 / 身份15 / 环境15 / 美术15 / 动作10 / 弧线10 / 摄影10）
生图 Prompt（英文）
视频 Prompt（英文）
连续性检查点（锁定字段 + 状态切换规则）
来源 ID + 实际链接；证据不足处标记 uncertainty
```

## 4. 角色设计块（复制）

```text
CHARACTER
- name: <角色名；虚构/真实>
- role: <职业/身份>
- economic_status: <low | middle | high>
- arc: <人物弧线，服装变化用，不做心理诊断>
- fidelity_mode: <historical | inspired | fictional>
- period_region: <PRD-ID 或 unknown>
- art_direction: <STY-ID 或风格词>

LOOK A (preferred)
- upper_body: <GAR-ID> <name_en> / <color> / <material>
- lower_body: <GAR-ID> ...
- one_piece: <GAR-ID> ...（与 upper+lower 二选一）
- outerwear: <GAR-ID> ...
- footwear: <GAR-ID> ...
- accessory: <GAR-ID> ...（最多 1–2 件，保持跨场可追踪）
- part: <STR-ID> ...（结构：领型/门襟/褶裥/闭合）
- material: <MAT-ID> ...（材质：垂坠/反光/老化）
- palette: <颜色 2–4 个>
- silhouette: <A/H/X/Y/straight/flared...>

LOOK B (clearly different alternative)
- 与 A 的差异点：<颜色/廓形/正式度/结构>

LOOK C (budget or art-direction alternative)
- 与 A 的差异点：<复用单品/低成本材质/更强美术方向>

CONTINUITY LOCK
- item ids: <GAR/STR/MAT IDs>
- colors / materials / trims: <锁定>
- accessory position: <左肩/腰间/手提>
- hair / makeup: <锁定>
- wetness: <dry | damp | wet | drying>（仅显式切换）
- damage / dirt: <none | ...>
- shots: <S1, S2, S3>
```

## 5. 严格度措辞（直接复制到 prompt）

- historical：`historically grounded period costume, period-accurate construction and materials, no modern fashion elements`
- inspired：`period-inspired modern interpretation, historical silhouette cues mixed with contemporary construction`
- fictional：`original fictional-world costume design, explicitly not a historical reconstruction, internally consistent world-building`

## 6. 负向约束（默认全选，按项目增删）

```text
no costume morphing between shots, no unexpected accessories, no color shift,
no logo, text or watermark, no extra layers appearing or disappearing,
no warped hands, no deformed body, no changing hairstyle between shots,
no instant drying between shots; wetness changes only on an explicit state transition,
no modern zippers / sneakers / printed t-shirts (historical mode only),
no unstable footwear, no wardrobe malfunction (dance/action only)
```

## 7. 已填写示例（虚构示例，非史实）

```text
CHARACTER: Lin / urban investigator (fictional) / economic low / fictional mode
LOOK A: upper GAR-EXAMPLE-001 off-white cotton stand-collar shirt
        outer (missing in starter vault; see gaps)
        footwear (missing in starter vault; see gaps)
palette: off white, charcoal
CONTINUITY LOCK: GAR-EXAMPLE-001 白色立领衬衫 off_white/cotton; left-shoulder canvas bag; wetness=dry; damage=none
NEGATIVE: no unexpected hat, no jewelry, no costume redesign between shots, no color shifts
```

> 注意：示例卡是 `example` 证据级别，不得作为史实引用。真实项目请把 ID 换成 Vault 中实际存在的 verified/interpretive 卡。
