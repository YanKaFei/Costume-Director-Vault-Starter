## 推荐浏览路径

1. 从 [[服装单品]] 选单品 → 看「结构线索」链到 [[结构细节]] 的对应类别；「材质线索」链到 [[材质纹样]]。
2. 从 [[时代地域]] 进入某语境卡，仅作为**语境参考**；具体单品关系不在此页断言。
3. 从 [[风格体系]] 看风格语言，再回 [[造型组合]] 的 LOOK（LOOK 的 `look_items` 是策展列表，不等于史实套装）。
4. 从任意卡片的 `## 来源链接` / [[来源证据]] 跳到来源；来源白名单以 `11-验收/P5/source-audit.csv`（migration_class）为准；`reports/SOURCES.csv` 为登记快照。
5. 需要「某单品 + 某部件/材料/时代」的可迁移关系：查 `11-验收/P5/RELATION-CANDIDATES.csv` 的 `migration_ready` 行，**不要**从本 MOC 猜关系。
