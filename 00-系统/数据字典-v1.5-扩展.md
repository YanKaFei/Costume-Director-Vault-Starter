# 数据字典 v1.5 扩展（视觉 Prompt 层，可选字段/正文区域）

本文件是 `00-系统/数据字典.md`（v1.1 必填 + v1.2/v1.3/v1.4 可选）的**向后兼容扩展**：只新增视觉提示层 optional 字段与可选正文区域；**不修改任何既有必填字段、枚举、8 节正文或证据规则**。旧卡无需迁移、保持合法。规范说明见 `00-系统/视觉规范.md`；模板见 `templates/visual-card-sections.md`。

## 1. 新增可选 YAML 字段（所有内容卡可选用）

| 字段 | 类型 | 允许值/说明 |
|---|---|---|
| `visual_prompt_profile` | enum | `material_macro` / `material_sample` / `material_application` / `material_video_light` / `component_closeup` / `component_technical` / `component_application` / `garment_item` / `garment_full_body` / `garment_side_back` / `garment_hero` / `accessory_object` / `accessory_detail` / `accessory_styled` / `footwear_object` / `footwear_detail` / `footwear_styled` / `style_reference_case` / `style_abc` / `style_character_scene` / `style_consistency` / `outfit_standard` / `outfit_abc` / `outfit_character_scene` / `outfit_consistency` / `unknown` |
| `visual_prompt_type` | list[string] | 可选子类型（如 `full_body` `detail` `technical_diagram` `video`）；每个词条小写下划线 |
| `visual_assets` | list[string] | 资产元数据字符串：`id=ASSET-xxxx; kind=...; source_ids=...; url=...; license=...; note=...`；**只登记元数据，不内嵌图片** |
| `visual_evidence` | list[string] | 覆盖标签：`FACT` / `OBSERVATION` / `INFERENCE` / `CREATIVE`；用于声明该卡视觉提示包含哪些证据层 |

```markdown

- ASSET-0001（external_reference；link_only；SRC-0100）：对象页结构/轮廓参考，不复制图片。

COLOR (FACT): ...
LIGHT (CREATIVE): ...
CAMERA (CREATIVE): ...
BACKGROUND (CREATIVE): ...
STYLE (INFERENCE): ...
NEGATIVE (CREATIVE): ...

## 视频提示词
SUBJECT (FACT): ...
CONSISTENCY (OBSERVATION): ...
LIGHT (CREATIVE): ...
CAMERA (CREATIVE): ...
NEGATIVE (CREATIVE): ...
```

- 旧卡没有上述区域仍合法；**不得**因新增视觉层修改正文既有事实或 8 节标题。
- `prompt_en` 仍是既有必填字段；`visual_prompt_profile`/正文提示词是可选补充，不能替代 `prompt_en`。
- `## 视觉参考` 中的 URL/许可必须独立登记，`source_ids` 只表示事实来源，不表示图像许可；不得把图片复制进 Vault。

## 3. 资产 ID 规则（摘要）

- `ASSET-\d{4}`，唯一/不复用/不删除；与 `GAR/STR/MAT/STY/PRD/LOOK/SCN/SRC` 分离。
- `kind`: `external_reference` / `licensed_reference` / `generated_diagram` / `own_photo`（需许可）。
- `license`: `cc0` / `cc_by` / `link_only` / `other_permission` / `unknown`；许可独立于来源。
- 禁止：内嵌/下载/复制图片；把资产 ID 写入 `source_ids`；把视觉参考当史实/物性证据。

## 4. 证据与反编造

- `FACT` 只能用于卡片字段/来源直接支撑的物性/结构；未支撑的纤维、克重、反光、透明、部件一律 `unknown` 或省略。
- `OBSERVATION` 用于可见参考/正文可观察；`INFERENCE` 为设计解释；`CREATIVE` 为镜头/光/背景/负面等创作选择。
- 不得从颜色/年代/风格词推断物理属性；不得把 `CREATIVE` 写进 `FACT` 或 `## 结构要点` 的事实断言。
- 视觉资产与 `source_ids`/许可分离；对外发布仍需逐图版权审查。

## 5. 兼容/校验

- 全部 optional；旧卡、旧 LOOK/Outfit、旧 relations 均合法，无需迁移。
- 当前 `scripts/validate.py` 不校验这些可选字段（与 v1.2+ 规则一致）；它们由视觉规范/人工审阅，不进事实校验；不得用可选字段绕过必填/证据规则。
- 本扩展不新建卡/资产/来源；不修改卡片。
