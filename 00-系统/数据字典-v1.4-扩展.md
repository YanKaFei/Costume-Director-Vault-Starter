# 数据字典 v1.4 扩展（Outfit 知识对象，可选字段）

本文件是 `00-系统/数据字典.md`（v1.1 必填 + v1.2/v1.3 可选）的**向后兼容扩展**：只新增 `type=look` 的可选字段，旧 LOOK 卡无需迁移、保持合法；不改变任何卡片事实/证据规则。模型说明见 `00-系统/Outfit模型.md`；验证器 `scripts/validate_outfits.py`。

## 1. 新增可选字段（`type=look`）

| 字段 | 类型 | 允许值/说明 |
|---|---|---|
| `outfit_slots` | list[string] | 每个元素 `slot=ID`；slot ∈ `inner_layer` `upper_body` `lower_body` `one_piece` `set` `outerwear` `footwear` `accessory` `carried_prop`；旧卡无此字段时从 `look_items` 推导（legacy 提示） |
| `evidence_type` | enum | `historical_evidence` / `sourced_style_observation` / `creative_inference`；新对象必填，旧卡缺省=legacy |
| `historical_evidence` | list[string] | 支撑组合的来源/断言（`SRC-xxxx` 或 `CARD:SRC`）；historical 分支必填 |
| `style_observation` | list[string]/string | 有来源的风格观察；不得当逐件史实 |
| `creative_inference` | list[string]/string | 设计/戏剧推断；必须显式标注 |
| `constraints_checked` | list[string] | 建议全含：`period` `region` `identity` `weather` `action` `compatibility` `approved_anchors` |
| `period_tiers` | list[string] `slot=tier` | 硬约束用；tier: `exact`/`era`/`approximate`/`none`/`unknown` |
| `region_tiers` | list[string] `slot=tier` | 同上 |
| `approved_anchors` | list[string] | 已批准 anchor ID；必须出现在 slots 中 |
| `context` | string/list | 使用语境（场景/场合/戏剧设定） |
| `character_function` | string | 角色功能（身份/职业/阶级/叙事功能） |
| `continuity_state` | string/list | 跨场状态（wetness/damage/dirt/accessories） |
| `outfit_silhouette` | string | 整体廓形（如 `A`/`H`/`Y`/`X`）；不替代结构卡 |
| `prompt_image` / `prompt_video` | string | 生图/视频英文 prompt（已存在则复用） |
| `relations` | list[string] | 与 `00-系统/关系类型.md` 一致；不因 Outfit 模型放宽历史断言 |

`periods`/`regions`/`style_tags`/`look_items`/`look_scene`/`continuity_lock`/`prompt_en` 等**复用既有字段**，不新增重复字段。

## 2. relation_type 枚举（Outfit `relations`，与 `00-系统/关系类型.md` v3 同步）

| relation_type | subject → object | 设计层 | factual | 最高置信 |
|---|---|---|---|---|
| `appears_in_look` | look → 内容 / material / pattern | 策展组合 | false（历史层） | medium（设计） |
| `look_appears_in_scene` | look → scene | 显式场景 | false（历史层） | medium |
| `context_includes` | period_region → garment/part | 语境级 | false（逐件历史） | high（compatible scope） |
| `in_style` | garment/part/look → style | 风格标签 | false（历史层） | high（精确 STY ID + 来源） |
| `style_interpretation` | look/garment/part → style；或 style → look（`R-CURATED-DESIGN`，engineer/task-76） | **design-only** | **false 固定** | **medium 固定；禁止 high** |
| `uses_material` | content → material | 材料族 | false（token） | medium（禁止 high） |
| `may_have_part` | garment → garment_part | 共现候选 | false（非 has_part） | medium（禁止 high） |
| `ensemble_with` | garment → footwear/accessory/headwear/carried_prop | 搭配候选 | false（非历史搭配） | medium（禁止 high） |
| `claim_supported_by` | content → source | 直接证据 | true（scope 匹配时） | high（verified） |

- `style_interpretation` 记录必须含 `factual=false`、`design_only=true`、`evidence=interpretive`、`confidence=medium`；`review_status=review_queue`，不得迁移为历史关系。
- `relations` 字符串可附加 `factual=true/false`、`design_only=true/false`；v1.1 扁平列表规则不变。
- **Agent 过滤**：历史问题只使用 `factual=true` 且 `evidence_level=direct_evidence` 的关系；`factual=false`/`design_only=true` 仅可用于设计说明，不得作为年代/地域/穿着事实。

## 3. 兼容/校验规则（原 §2 顺延）


- 旧 LOOK 卡无以上字段仍合法；`validate_outfits.py` 标 `legacy` 并给 warning，不判失败。
- 任一新字段出现即视为新对象：必须有 `evidence_type`，并按分支提供必备字段/完整 slots/通过 `outfit.py` 硬约束。
- `historical_evidence` 分支不得含 example 卡；不得用 `sourced_style_observation`/`creative_inference` 冒充史实。
- 所有字段扁平（list[string]/string/enum），禁止嵌套 map；`outfit_slots` 用 `slot=ID` 字符串而非对象列表。
- `approved_anchors` 缺失/缺项 → fail（approved anchor 保护）。
- `relations` 仍受 P5-B 五级证据/规则约束；Outfit 模型不改变 `source_ids` 或事实。
