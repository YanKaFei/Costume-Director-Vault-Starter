# 数据字典 v1.2 扩展（兼容性可选字段）

本文件是 `00-系统/数据字典.md` v1.1 的**向后兼容扩展**：只新增**可选字段**，不修改、不重命名、不删除任何既有必填字段与枚举。旧卡（v1.0/v1.1）保持合法，无需迁移；新卡可按需使用这些字段提升结构/配饰描述精度。校验器遇到未知字段应忽略（当前 `scripts/validate.py` 只校验必填字段、枚举、列表类型与链接，不拒绝额外字段）。

> 原则：可选项 = 知道才写，不知道不写；不得用可选字段替代必填字段（`category`/`subcategory`/`silhouette`/`fit` 等仍按 v1.1 要求）。可选字段本身不改变 `evidence_status`：是否 verified 仍取决于来源卡与正文断言。

## 3. 使用规则

1. 可选项只在有把握时填；不知道就省略，不用伪精确值。
2. 可选项不得与必填字段冲突（如 `fit_class` 与 `fit` 应一致；`length_class` 与正文描述一致）。
3. 来自具体馆藏/文献的可选值应在正文/来源链接中可追溯；仅凭常识的结构词（如某些 sleeve_shape）应标 interpretive。
4. 可选项不参与 `evidence_status` 判定，但若某卡的主要断言依赖可选项事实，仍需真实来源。
5. 词表扩展优先复用本文件；新增值需在本文件登记并同步 v1.2 版本说明。
