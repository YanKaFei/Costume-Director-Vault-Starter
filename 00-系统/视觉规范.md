# 视觉规范 — 类型化 Prompt Schema（R1.3-B）

- 版本：v1（2026-11-05，task-105）；性质：**可选、向后兼容**的视觉提示层，不替代现有 `prompt_en`/正文 8 节，不修改卡片事实。
- 配套：`00-系统/数据字典-v1.5-扩展.md`（字段/枚举）、`templates/visual-card-sections.md`（模板）、`reports/R1.3-PROMPT-SCHEMA.md`（说明/验收）。
- 目标：让导演/设计/摄影从卡片生成**可复制、可核查、可追责**的英文视觉提示；杜绝“无来源物性/细节”的编造。

## 1. 原则

1. **先证据、后提示**：每个提示模块必须带 `FACT` / `OBSERVATION` / `INFERENCE` / `CREATIVE` 标签；`FACT` 仅用于卡片字段/来源可直接支撑的内容。
2. **不编造物理属性**：材料纤维、组织、克重、反光、透明度、结构部件等，未在 `materials`/`fiber_content`/`hand_feel`/结构字段/来源中出现时，写 `unknown` 或省略；不得从颜色/年代/风格词推断。
3. **英文可复制**：模块输出英文短语，保持可粘贴到生图/视频工具；中文作为术语对照，不作为唯一输出。
4. **资产与许可分离**：视觉参考使用 `ASSET-xxxx` 元数据 ID；资产 URL/许可独立登记，**不内嵌/不下载/不复制图片**。卡片的 `source_ids` 仍是事实来源，不是图像许可。
5. **旧卡不迁移**：新字段/正文区域全部 optional；旧卡无视觉层仍合法；校验器不因缺失而失败。

## 2. 类型化 Prompt Profile

`visual_prompt_profile`（optional enum，一张卡可写 1 个主 profile；多用途在正文列多个变体）：

| 卡片域 | profile | 用途/镜头 |
|---|---|---|
| material | `material_macro` | 微距：纤维/组织/表面（仅写有证据的属性） |
| material | `material_sample` | 平铺样本/色卡/质地对照 |
| material | `material_application` | 材料在服装上的实际应用（不虚构服装形制） |
| material | `material_video_light` | 视频：运动/折叠/光线变化（不新增物性） |
| component | `component_closeup` | 部件局部特写（领/袖/腰/门襟/扣合等） |
| component | `component_technical` | 技术图/结构示意（标 INFERENCE 部分） |
| component | `component_application` | 部件在完整服装上的应用 |
| garment | `garment_item` | 单品正面/平铺 |
| garment | `garment_full_body` | 全身穿着 |
| garment | `garment_side_back` | 侧面/背面/细节 |
| garment | `garment_hero` | 定妆/主视觉 |
| accessory/footwear | `accessory_object` / `footwear_object` | 实物单品 |
| accessory/footwear | `accessory_detail` / `footwear_detail` | 五金/缝线/鞋跟/鞋底等细节 |
| accessory/footwear | `accessory_styled` / `footwear_styled` | 穿搭/情境 |
| style | `style_reference_case` | 标准案例/风格板 |
| style | `style_abc` | A/B/C 风格变体 |
| style | `style_character_scene` | 人物/场景应用 |
| style | `style_consistency` | 跨镜头一致性 |
| outfit | `outfit_standard` / `outfit_abc` / `outfit_character_scene` / `outfit_consistency` | 完整造型/变体/人物场景/连续性 |

## 3. 十个模块（顺序固定，可省略无证据模块）

| 模块 | 内容 | 默认证据标签 | 规则 |
|---|---|---|---|
| `SUBJECT` | 主体（人/单品/部件）、数量、姿态、画幅 | FACT（身份）/ OBSERVATION（姿态） | 不写未提供的姓名/身份/情绪 |
| `STRUCTURE` | 领/袖/肩/腰/摆/门襟/裁片/接缝等 | FACT（有结构字段/来源） | 未写字段 → `unknown`，不得补造 |
| `MATERIAL` | 纤维/组织/表面/厚薄/反光/透明 | FACT（有 materials/fiber_content/来源） | 不得凭外观推断纤维/克重 |
| `COLOR` | 主色/辅色/配色关系 | FACT（colors 字段）/ OBSERVATION | 不发明未列色彩 |
| `LIGHT` | 光源/方向/色温/反差 | OBSERVATION / CREATIVE | 布光是摄影设计，不是服装事实 |
| `CAMERA` | 镜头/景别/角度/景深/画幅 | CREATIVE | 设计选择，非史实 |
| `BACKGROUND` | 场景/环境/道具 | OBSERVATION / CREATIVE | 场景不作为服装证据 |
| `STYLE` | 风格语言/艺术方向 | INFERENCE / CREATIVE | 标注设计解释，不是历史风格事实 |
| `NEGATIVE` | 禁止项（时代错误/多余配饰/变形） | CREATIVE | 不得把 negative 写成事实 |
| `CONSISTENCY` | 跨镜头恒定项（颜色/结构/配饰位置/状态） | OBSERVATION | 有 `continuity_lock` 时引用；不新增事实 |

### 3.1 英文可复制格式（示例）

```text
SUBJECT (FACT): adult standing figure, full body, centered, historical 1820s day dress.
STRUCTURE (FACT): high round neckline; long puffed and pleated sleeves; high waistline; back fastening.
MATERIAL (FACT): white muslin, plain-weave cotton, matte, slightly sheer.
COLOR (FACT): white/undyed; no printed pattern specified.
LIGHT (CREATIVE): soft north window daylight, low contrast, gentle falloff.
CAMERA (CREATIVE): 50mm lens, full-body vertical frame, eye level, f/4.
BACKGROUND (CREATIVE): neutral pale studio wall, no props.
STYLE (INFERENCE): restrained neoclassical daywear, no theatrical exaggeration.
NEGATIVE (CREATIVE): no zipper, no elastic, no modern shoes, no extra jewelry, no pattern invention.
CONSISTENCY (OBSERVATION): keep neckline shape, sleeve volume, waistline height and white palette identical across shots.
```

## 4. 证据标签

| 标签 | 含义 | 允许来源 | 禁止 |
|---|---|---|---|
| `FACT` | 卡片字段/来源直接支撑 | `source_ids`/结构字段/材料字段 | 不得用于猜测/风格词 |
| `OBSERVATION` | 从可见参考/字段可观察，但非精确记录 | 视觉资产/正文描述 | 不得升级为史实/物性 |
| `INFERENCE` | 基于证据的合理推断/设计解释 | 结构/风格/语境 | 不得写成“当时事实” |
| `CREATIVE` | 摄影/美术/风格选择 | 导演/设计 | 不得冒充服装史/来源 |

**硬规则**：`MATERIAL`/`STRUCTURE` 中的物性/结构必须在卡内有字段或来源；没有就 `unknown`；`FACT` 不得来自 `CREATIVE` 的镜头选择。

## 5. 资产 ID 规则（ASSET）

- 格式：`ASSET-\d{4}`（`ASSET-0001` 起）；唯一、不复用、不删除；与 `GAR/STR/MAT/STY/PRD/LOOK/SCN/SRC` 命名空间分离。
- `visual_assets` 只存**元数据**，不存图片：
  `"id=ASSET-0001; kind=external_reference; source_ids=SRC-0100; url=https://...; license=link_only; note=object page only"`
  - `kind`: `external_reference` / `licensed_reference` / `generated_diagram` / `own_photo`（需许可）
  - `license`: `cc0` / `cc_by` / `link_only` / `other_permission` / `unknown`（**资产许可独立于 `source_ids`**）
  - `url`: 仅链接；禁止内嵌/下载/复制进 Vault/PPT/生成服务。
- 图片/参考不能替代卡片事实；资产 ID 不是来源 ID，不得写进 `source_ids`。
- 示例 `ASSET-0001` 为**占位示例**，不代表已登记资产；真正资产需另立登记/许可核验，不自动生成。

## 6. 可选 YAML 字段与正文区域（向后兼容）

```yaml
visual_prompt_profile: garment_full_body   # optional enum
visual_prompt_type: [full_body, detail]    # optional list of subtypes
visual_assets:                             # optional flat list[string]
  - "id=ASSET-0001; kind=external_reference; source_ids=SRC-0100; url=https://collections.vam.ac.uk/item/O.../; license=link_only; note=object page only"
visual_evidence: [FACT, OBSERVATION, INFERENCE, CREATIVE]  # optional coverage tags
```

正文可选区域（不取代 8 节）：

```markdown
## 视觉参考
- ASSET-0001（external_reference；link_only；SRC-0100）：对象页结构/轮廓参考，不复制图片。

## 生图提示词
SUBJECT (FACT): ...
STRUCTURE (FACT): ...
MATERIAL (FACT): ...
COLOR (FACT): ...
LIGHT (CREATIVE): ...
CAMERA (CREATIVE): ...
BACKGROUND (CREATIVE): ...
STYLE (INFERENCE): ...
NEGATIVE (CREATIVE): ...

## 视频提示词
SUBJECT (FACT): ...
CONSISTENCY (OBSERVATION): ...
LIGHT (CREATIVE): ...
CAMERA (CREATIVE): ...
NEGATIVE (CREATIVE): ...
```

- 旧卡无上述字段/区域仍合法；`prompt_en` 仍是既有必填片段，不能被 `视觉规范` 替代。
- 正文区域是**追加**，不改动 8 节事实；视觉参考/生图/视频不得写“已验证/馆藏事实”，除非引用 `SRC`。

## 7. 兼容性/边界

- 数据字典 v1.5 只新增 optional 字段/正文区域；旧卡、旧 LOOK/Outfit、旧 relations 全部合法。
- 本规范不新建卡片、不新增资产、不改来源；不把视觉资产等同于图片许可或历史证据。
- `visual_prompt_profile` 与 `prompt_en` 并存：profile 选择“拍什么/怎么拍”，`prompt_en` 提供既有片段；两者可组合。
- 提示词不得包含未登记资产 URL/许可承诺；对外发布需独立图像权利审查。
