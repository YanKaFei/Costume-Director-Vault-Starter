# 数据字典 v1.3 扩展（许可字段与迁移字段，向后兼容）

本文件是 `00-系统/数据字典.md` v1.1/v1.2 基础上的**向后兼容可选扩展**：只新增可选字段，不修改任何 v1.1 必填字段、枚举、8 节正文或证据规则。旧卡无需迁移，保持合法。

## 1. 新增可选字段

| 字段 | 类型 | 适用 type | 允许值 | 用途 |
|---|---|---|---|---|
| `content_license` | string | source | `cc0` `cc_by` `cc_by_sa` `cc_by_nc` `cc_by_nc_sa` `other_permission` `link_only` `not_applicable` `unknown` | **内容/文字/数据**许可（与图像许可分开） |
| `image_license` | string | source | `cc0` `cc_by` `cc_by_sa` `cc_by_nc` `cc_by_nc_sa` `other_permission` `link_only` `not_applicable` `unknown` | **图像**许可；未逐图核验时默认 `link_only` |
| `license_verified` | string | source | `verified` `partial` `not_applicable` `unknown` | 内容与图像许可是否分别核验：`partial`=一侧清楚、另一侧未核验 |
| `superseded_by` | string | 内容卡 | 已存在的卡片 ID | 迁移/合并后指向 canonical（保留旧 ID，不删除） |
| `deprecated` | string | 内容卡 | `'true'` / `'false'` | 旧卡标记为 redirect/deprecated；检索时应降权或排除（用字符串避免 YAML bool 触发 validate 字段类型 WARN） |
| `canonical_id` | string | 内容卡 | 已存在的卡片 ID | 声明本卡为某主题的 canonical（可选） |

说明：
- `license_status`（v1.1）保留为**总览/兼容字段**；新卡或修订卡应优先写 `content_license` + `image_license`，并在 `rights_statement` 使用固定句式：「内容许可 X；图像许可 Y；本项目仅链接引用，不嵌入」。
- 图像许可不允许因内容许可宽松而自动推定为可复用；未核验时一律 `image_license: link_only`，与全库 0 图片策略一致。
- `superseded_by`/`deprecated` 只用于旧 ID 的 redirect stub；被替代卡的正文与来源保留，不删除已验证内容。

## 2. 兼容性与回滚

- 旧卡不写这些字段仍合法；`scripts/validate.py` 当前不校验这些可选字段（只校验必填/枚举/正文/链接），因此字段错误不会导致 PASS 失败，需 QA/审计脚本另行检查。
- 回滚：删除本文件与数据字典 §11 的 v1.3 版本行；删除本次新增的可选字段即可（卡片正文与来源不变）。或 `git revert`。
