# 来源和图像许可规范

1. 任何 `verified` 的历史、工艺、文化断言必须附真实来源；不要凭模型记忆伪造馆藏编号。
2. 图片与文字数据的权利分别核验。The Met 的开放 CSV 数据与其图片权利不是同一个概念；只有确认图片本身带 CC0 标识等合法授权，才可复制到项目内。
3. 版权不清晰的服装图片只存原始 URL、作者、标题、访问日期、权利状态 `link_only`，不批量抓取。
4. 博物馆、学术机构、原始服装图录优先。尽量避免无来源的营销博客和转载图。
5. 史实与导演创作分开：`verified` 标明证据范围，`interpretive` 说明艺术性判断，`example` 明确只是模板示例。
6. 来源元数据：`source_id, title, publisher, url, accessed_at, source_kind, rights_statement, note`。

来源起点：Fashionpedia / Getty AAT / FIT Fashion History Timeline / Met Open Access / Costume Designers Guild / Screen Ireland Costume Department。
