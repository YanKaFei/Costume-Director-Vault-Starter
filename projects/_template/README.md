# Project template

Copy this directory to `projects/<your-project>/` and fill:

- `script.txt` — the script/scene excerpt (verbatim; do not edit the KB)
- `meta.json` — characters, period/region/culture, art/cinematic style, lighting,
  environment/weather, budget, action constraints, stages, scene states
- `characters/` — casting/character notes and references
- `outputs/` — generated workflow outputs

Unknown fields stay `unknown`; do not invent IDs or sources.
