# 《麦克白》18 套造型人工评分表（空白，不代填）

- 用途：由人类评审（导演/服装设计/历史顾问/摄影）对 `LOOKS.md` 的 18 套造型打分。
- 评分制：**1–5 分**（1=明显不合格，3=可用但有明显问题，5=优秀）；允许 0.5 分。
- **本文件不代填分数**；`—` 表示待人工填写。请在每列标题下签注评审姓名与日期。
- 建议评审流程：先独立打分，再开会对照 `EVIDENCE.md` 的 historical/evidence/theatrical 标注与缺口，最后记录修改意见。

## 评分维度（7 维）

| # | 维度 | 说明 |
|---|---|---|
| R1 | 历史/证据分寸 | 是否清楚区分 historical / evidence-analogue / theatrical；是否把类比误当史实 |
| R2 | 角色与弧线 | 是否服务 Macbeth / Lady Macbeth 的阶段变化与人物关系 |
| R3 | 视觉世界一致性 | 两角色是否共享同一物质世界（材质、色彩、光）且各有身份差异 |
| R4 | A/B/C 实质差异 | 同阶段三套是否真正不同（结构/色彩/叙事），而非只换一件配饰 |
| R5 | 连续性与可执行性 | 血/烟灰/头发/锚点物是否可跨场管理；A/B/C 是否可实际制作 |
| R6 | prompt 可执行性 | 英文生图/视频 prompt 是否具体、无版权风险、可直接用于生成 |
| R7 | 风险与伦理 | 文化/历史误用、材料安全、演员舒适度、超自然场次的表达风险 |
