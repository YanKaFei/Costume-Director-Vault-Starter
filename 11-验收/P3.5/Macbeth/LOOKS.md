# 《麦克白》18 套阶段造型（LOOKS）

- 角色：Macbeth（M1 野心上升 / M2 罪恶危机 / M3 覆灭）× A/B/C；Lady Macbeth（L1 / L2 / L3）× A/B/C = **18 套**。
- 全部引用知识库真实 ID（01-03 磁盘现状）：GAR-0075–0082（欧洲/地中海中世纪—早期近代**类比**卡）、GAR-0009、GAR-0061、GAR-0062、GAR-0068、GAR-0024、GAR-0003、MAT-0011、MAT-0003、STR-0006。
- **证据边界**：这些卡都不是 11 世纪苏格兰实物；`historical` 层一律写“无直接证据”，`evidence` 层写具体类比卡与 SRC，`theatrical` 层写艺术推断。GAR-0079 基尔特长袍为 interpretive（无馆藏来源），不得当作 verified。
- A/B/C 不是换色：A 为基本实用/基础层，B 增加外层/武器或公开身份层，C 改变廓形/年代或做明确的 theatrical 设计。详细证据见 `EVIDENCE.md`；场次映射见 `SCENE-TABLE.md`。
- 全局缺口：无中世纪 wimple/coif（GAR-0068 是 1902 婚礼头纱，只能 theatrical）、无锁甲/板甲/头盔、无王冠/权杖/regalia、无中世纪女鞋（GAR-0024 为 16–18 世纪）、无中世纪珠宝（GAR-0073/0074 为维多利亚哀悼珠宝，未使用）。血、泥、烟灰均为道具/化妆连续性，不是 KB 卡。

## M1-A — Macbeth / M1 野心上升 / A 实用战场层（evidence-led）

**KB 引用**：GAR-0075 束腰长袍（SRC-0480/0481）；GAR-0077 紧身长袜（SRC-0484/0485）；GAR-0080 腰带（SRC-0487/0488）；GAR-0081 皮靴（SRC-0489）

**来源 SRC**：SRC-0480/0481（GAR-0075）、SRC-0484/0485（GAR-0077）、SRC-0487/0488（GAR-0080）、SRC-0489（GAR-0081）

**风险**：长袜与腰带扣为早期近代/中世纪早期类比，年代跨度大；靴为 15 世纪，不可当作 11 世纪鞋履证据；无护甲，战场戏需动作设计避免受伤。
