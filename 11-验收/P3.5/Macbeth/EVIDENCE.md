# 《麦克白》18 套造型证据表（KB 卡、来源、缺口）

- 证据原则：`historical`（11 世纪苏格兰直接证据）在本知识库为 **无**；`evidence` 指有馆藏/来源的欧洲/地中海中世纪—早期近代**类比**卡；`theatrical` 指明确的艺术推断。三者不得混写。
- 所有 KB ID 均来自 01–03 磁盘现状（2026-11-04 本轮读取）；未使用任何虚构 ID。
- 关键边界：GAR-0075–0082 是 architect 新补的**欧洲/地中海类比卡**，卡片自身带“## 证据边界（analogue）”声明；GAR-0079 基尔特长袍为 **interpretive（无馆藏来源）**，不得标 verified；GAR-0068 婚礼头纱为 1902 年英国实例，**只能 theatrical 使用**，不能当中世纪 wimple/veil 证据。

## 2. 全局缺口（不编造，逐项声明）

| 缺口 | 影响 | 处理 |
|---|---|---|
| **11 世纪苏格兰直接服饰证据** | 本案例无法做“历史复原” | 所有造型均为 analogue + theatrical；`historical` 层写“无直接证据” |
| 中世纪 wimple / coif / 头巾 | Lady Macbeth 无法做“中世纪头部包覆”的历史层 | 不发明；L2-C/L3-C 用 GAR-0068 1902 头纱，标 theatrical；L3-A 用散发 |
| 锁甲/板甲/头盔 | Macbeth 战场/终局无真实护甲 | 用 GAR-0003 杰金（15–16 世纪皮革外套）作“类比防护层”，明确不是护甲；无头盔，靠发型/阴影 |
| 王冠/权杖/regalia | M2/M3 的“王权”只能靠服装与调度 | 不使用虚构王冠；以 dalmatic/斗篷/过大版型表达，缺口在风险中标注 |
| 中世纪女鞋 | Lady 只有 GAR-0024 穆勒鞋（16–18 世纪） | 作为最近可用类比；标注年代差；室内/软底场景使用 |
| 中世纪珠宝 | 无 11 世纪珠宝卡（GAR-0073/0074 为维多利亚哀悼珠宝，未使用） | L1/L2 不配珠宝，靠层搭与面料；L3 去除所有装饰 |
| 血/泥/烟灰/匕首安全道具 | 无“血渍”材质卡；GAR-0082 为真实匕首卡 | 血/泥/灰为化妆与道具连续性；匕首必须用未开刃复制品（卡内已标风险） |
| 苏格兰/凯尔特纹样 | 无 tartan/格子呢卡 | 全部造型禁止 tartan（18–19 世纪联想），已在负向 prompt 中排除 |
