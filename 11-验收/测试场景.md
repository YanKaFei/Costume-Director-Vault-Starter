## 运行方式

```bash

python3 scripts/run_acceptance.py

python3 scripts/run_acceptance.py --no-write
```

## 每个结果文件必须包含

- 实际输入 JSON（完整）
- 实际执行命令与 **退出码**（`recommend.py`、`query.py`）
- `query.py` 检索命中卡片 ID
- `recommend.py` 候选池与实际选中的 A/B/C 单品/结构/材质 ID
- 三套 Look 的评分明细与总分
- 生图 / 视频 Prompt（实际输出）
- 风险、证据（source_ids + 实际 URL）
- 判定表：逐项 PASS/FAIL 与理由
- 备注：脚本 warning、知识库缺口

## 判定规则

- **PASS**：该用例声明的全部检查项均为 PASS。
- **FAIL**：任一声明检查项失败；必须写明实际值（不得用“应该”“大概”）。
- **PARTIAL**：仅在人工补充说明中使用；SUMMARY 只统计 PASS/FAIL。
- 历史模式用例若知识库缺少可核验的年代卡，必须判 FAIL 并记录缺口，不得用 example/interpretive 卡冒充史实。
- 脚本必须真实运行；若 `recommend.py` 返回退出码 3（无候选），该用例直接 FAIL，并记录缺口。

## 已知知识库缺口（如实记录）

- **1930 年代上海补齐情况**：已新增 `PRD-0011`（1930s 上海民国语境）、`LOOK-0008`（长衫知识分子 Look）、`SCN-0004`（上海知识分子对话）、`GAR-0031` 旗袍 / `GAR-0032` 长衫 / `GAR-0033` 西式休闲西装 / `GAR-0034` 针织背心 / `GAR-0035` 女式皮鞋、`STR-0011` 盘扣；T01 的 `region_evidence` 已 PASS（GAR-0031 旗袍）。剩余缺口：无 1930s 上海外层大衣/雨具/包袋/学生装/中山装卡；无女性旗袍 Look 卡（look_items 至少需 3 个 ID，目前只有 GAR-0031 + STR-0011）；GAR-0033 是英国 1930s–40s 馆藏，上海用法属 interpretive 而非史实；T01 雨天场景只能退而使用 GAR-0019 派克大衣作为外层，输出中以 region mismatch 风险明确标注。
- **当代衣柜**：当代（contemporary）单品仅少量（dashiki、trousers、parka、boots、1930s 女鞋），T04/T06/T09/T14/T15/T18 的现代场景因此更多依赖历史卡片的“inspired”兼容；测试只验证决策链路，不声称现代衣柜已完备。
- **结构/材质链接**：部分 garment 卡正文未显式 wikilink STR 卡，推荐会给出 `confidence: suggested` 的结构建议（按年代+部位匹配），在结果中明确标注，不当作史料断言。
- **雨天鞋履**：无防水/1930s 天气适配鞋卡；规则会在无替代品时保留“最不差”鞋履并写入风险，而不是返回缺鞋 Look。
