## 2. Evidence tags and conflicts

Tags: **FACT / OBSERVATION / INFERENCE / CREATIVE**. Verified card/source fields
are FACT; visual/lighting/movement prose is OBSERVATION; interpretive design
reading is INFERENCE; staging/art-direction is CREATIVE.

Conflict checks:
- missing material / structure / source;
- period/region mismatch (`--period`, `--region`);
- low-confidence/example cards;
- kind/card type mismatch (e.g. `outfit` on a non-LOOK).

Example conflict run (`GAR-0015`, `--period 1930s`):
`period_conflict`; `outfit` on GAR yields `kind_type_mismatch`;
`GAR-EXAMPLE-001` yields `low_confidence`.

`"delivery": "text prompt only"`; `--record` appends a JSONL generation record with
no image claim (`11-验收/R1.3/PROMPT-LOG.jsonl`).

# Prompt-English quality fix (lead review)

## Root cause

`prompt_en` was assembled from `name_zh`, `## 结构要点`/`## 视觉辨识` Chinese body
paragraphs, and raw card text. It therefore leaked CJK, `[[...]]` wikilinks,
markdown remnants, and a typo (`silhhouette`) into English prompts.

## Fix

`visual_prompt.py` now builds English only from sanitized English fields:
`name_en`, category/subcategory, silhouette, fit, materials, colors, periods,
regions, English `prompt_en`/`negative_prompt_en`, and short English
lighting/movement observations. `safe_english()` strips CJK, wikilinks, markdown,
and clips at word boundaries (no mid-token truncation). `prompt_zh` may retain
Chinese but has wikilink/markdown markup stripped. No raw Chinese body paragraph is
concatenated into `prompt_en`.

## Before / after example — GAR-0008 / garment_flat

**Before (bad):**
```
马甲, flat lay ... silhhouette straight; - 无袖、及腰、前开扣；... [[STR-0006-胸衣插片|胸衣插片]] ... may_have_par; ...
```
CJK present; wikilinks present; typo present.

**After (clean English):**
```
waistcoat flat lay on neutral background front and back true scale no model
silhouette straight fit slim category upper body/waistcoat materials wool silk
cotton palette black cream embroidered reference prompt fitted sleeveless
waistcoat single- or double-breasted buttoned front waist-length worn between
shirt and jacket matching or contrasting fabric
```
No CJK, no `[[`/`]]`, no `silhhouette`, no truncated token.
