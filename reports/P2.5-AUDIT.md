### 5.2 FAIL：historical 1940s–1970s 请求崩溃（exit 1）

证据：1940s / 1950s / 1960s / 1970s 均 `exit=1`，stderr：
```

```
根因（代码审阅，未修改）：`pick_looks()` 在候选不足 3 套时提前 `return [a]` / `[a, b]`（recommend.py 约 1498/1506 行），这些 look 是 `full=False` 版本，没有 `evidence` 字段；`make_result()` 在 2158 行无条件访问 `look["evidence"]` → 崩溃。
影响：historical 模式 + 候选组合 <3 的年代/地域会直接不可用（不返回部分结果、不声明证据不足）；inspired/fictional 模式可绕过（1970s inspired 实测 exit 0）。

### 5.3 A/B/C 实质差异（WARN）

- 16 个 standard 用例（T03/T17 为连续性单 Look）：

## 11. 建议（按严重度）

**P0（正确性）**
1. 修 `recommend.py` 崩溃：`pick_looks()` 的所有返回路径统一转 `full=True`（补 `evidence`/prompt），或在 `make_result` 对缺失 `evidence` 的 look 容错并补「looks<3」warning。
2. period/region 归一化层（decade→century→era；1580s→16th_century、italy⊂europe），只有归一化后仍无候选才 exit 3；修复 C08/Byzantine 假阴性。
3. warnings 覆盖：example 卡入选、职业/文化/气候/年代缺口、跨 region 借用、冲突 art_direction；不能只在「零候选」时 warning。

**P1（质量）**
4. 给 garment 增加环境/职业/场合约束（indoor/outdoor/rain/snow/medical/ceremonial）与性别/文化标签；禁止北极派克进入室内/雨戏硬约束。
5. example 卡不得进 A 套；prompt 加 `[EXAMPLE]` 或整 look 标 example。
6. prompt 只取已选 items 的 `prompt_en`，剔除卡片正文里未选中的「worn in snow / with leather jacket」等串文。
7. A/B/C 差异阈值（C 比 A 成本低 ≥10% 或复用 A ≥2 件，B 与 A 差异 ≥2 件），否则重算并 warning。
8. query 默认或可选把 example 卡降权/排除，并修正 `1930s 上海` 的核心卡排序。

**P2（覆盖）**
9. 补现代职业服（scrub/PPE/工牌）、雨衣/风衣、男鞋、勋章/徽章、未来基底等缺口；把 19 张 AAT 与 60 张未引用来源接入内容卡。
