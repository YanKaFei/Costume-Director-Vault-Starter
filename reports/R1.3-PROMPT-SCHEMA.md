## 1. 类型化 profiles（按域）

| 域 | profile（可选一个主 profile） | 建议镜头/用途 |
|---|---|---|
| material | `material_macro` / `material_sample` / `material_application` / `material_video_light` | 微距/样本/服装应用/视频运动光线 |
| component | `component_closeup` / `component_technical` / `component_application` | 局部特写/技术图/完整应用 |
| garment | `garment_item` / `garment_full_body` / `garment_side_back` / `garment_hero` | 单品/全身/侧背/定妆 |
| accessory / footwear | `accessory_object` / `accessory_detail` / `accessory_styled`；`footwear_object` / `footwear_detail` / `footwear_styled` | 实物/细节/穿搭 |
| style | `style_reference_case` / `style_abc` / `style_character_scene` / `style_consistency` | 标准案例/A-B-C/人物场景/一致性 |
| outfit | `outfit_standard` / `outfit_abc` / `outfit_character_scene` / `outfit_consistency` | 完整造型/变体/场景/连续性 |
| 未知/不适用 | `unknown` | 不强行套 profile |

- `visual_prompt_type` 用于子类型补充（如 `full_body`、`detail`、`technical_diagram`、`video`），**不是**事实字段。
- profile 选择“拍什么/怎么拍”，不改变卡片的事实/证据级别；不能替代 `prompt_en`。

## 2. 十个模块（固定顺序，可省略无证据模块）

| 模块 | 内容 | 默认证据 | 反编造规则 |
|---|---|---|---|
| SUBJECT | 主体/数量/姿态/画幅 | FACT/OBSERVATION | 不加未提供身份/情绪 |
| STRUCTURE | 领/袖/肩/腰/摆/门襟/裁片/接缝 | FACT | 未在字段/来源出现 → `unknown` |
| MATERIAL | 纤维/组织/厚薄/反光/透明 | FACT | 不从颜色/年代推断物性 |
| COLOR | 主色/辅色/配色 | FACT/OBSERVATION | 不发明未列颜色 |
| LIGHT | 光源/方向/色温/反差 | OBSERVATION/CREATIVE | 布光不是服装事实 |
| CAMERA | 镜头/景别/角度/景深 | CREATIVE | 摄影设计 |
| BACKGROUND | 场景/环境/道具 | OBSERVATION/CREATIVE | 场景不证服装 |
| STYLE | 风格语言/艺术方向 | INFERENCE/CREATIVE | 设计解释，不是史实风格 |
| NEGATIVE | 禁止项/时代错误/变形 | CREATIVE | 不写成事实 |
| CONSISTENCY | 跨镜头恒定项 | OBSERVATION | 有 `continuity_lock` 时引用，不新增 |

## 3. 英文可复制示例（garment_full_body）

```text
SUBJECT (FACT): adult standing figure, full body, centered vertical frame, historical 1820s day dress.
STRUCTURE (FACT): high round neckline; long puffed and pleated sleeves; high waistline; back fastening.
MATERIAL (FACT): white muslin, plain-weave cotton, matte, slightly sheer.
COLOR (FACT): white/undyed; no printed pattern specified.
LIGHT (CREATIVE): soft north-window daylight, low contrast, gentle falloff.
CAMERA (CREATIVE): 50mm lens, full-body, eye level, f/4, clean separation.
BACKGROUND (CREATIVE): neutral pale studio wall, no props.
STYLE (INFERENCE): restrained neoclassical daywear, no theatrical exaggeration.
NEGATIVE (CREATIVE): no anachronistic closures, no extra jewelry, no invented pattern, no costume morphing.
CONSISTENCY (OBSERVATION): keep neckline, sleeve volume, waistline height and white palette identical across shots.
```

- 每行前缀证据标签；中文术语对照见 `templates/visual-card-sections.md` §5。
- `FACT` 行只能来自卡内字段/`source_ids`；`CREATIVE` 不得偷写成 FACT。

## 4. 资产 ID 与许可

- 格式 `ASSET-\d{4}`（如 `ASSET-0001`）；唯一、不复用、不删除；与 `GAR/STR/MAT/STY/PRD/LOOK/SCN/SRC` 分离。
- `visual_assets` 只登记元数据字符串：`id=ASSET-xxxx; kind=external_reference|licensed_reference|generated_diagram|own_photo; source_ids=...; url=...; license=cc0|cc_by|link_only|other_permission|unknown; note=...`
- **资产许可独立于 `source_ids`**：`source_ids` 是事实来源；图像/参考的许可必须逐项核验；不内嵌/不下载/不复制图片；不得把 asset ID 写进 `source_ids`。
- 本任务 **未登记任何真实 ASSET**；模板中的 `ASSET-0001` 仅为占位示例，不能当已授权资产。
- 对外发布仍需逐图权利审查（B2 等门禁不变）。
