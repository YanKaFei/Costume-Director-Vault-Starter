# R1.3B Batch3 — Similarity QA and 20-sample fix

- Pair audit: `11-验收/R1.3B/SIMILARITY-QA.csv` (597 pairs), `.md`, summary JSON
- Sample fix: `11-验收/R1.3B/SIMILARITY-SAMPLE-FIX.csv` (20 cards)
- Prompt-only edits; no facts/source_ids/evidence_status changed.
- No image generation or human visual approval.

## 1. 597-pair classification

The audit slice is the lead-reported **597** content-similarity pairs. Categories
are based on card types and raw/content similarity:

| Category | Count |
| --- | ---: |
| same_structure_or_silhouette (garment/garment_part) | 346 |
| same_material_surface (material cards) | 110 |
| style_rename_only (style cards) | 105 |
| conflict_period | 23 |
| same_character_silhouette | 6 |
| other_professional | 7 |
| **Total** | **597** |

Additionally, **public template-scaffold** pairs (raw >=0.82 with content below the
professional threshold) remain reported separately by `prompt_qa.py`; they are not
counted as professional duplicates.

## 2. 20-sample fix

20 cards across style/material/structure/garment were selected from the highest
similarity clusters. Each image base prompt received a card-specific
`DISTINCTION (FACT)` line built only from existing fields (`name_en`, type,
category, silhouette, materials, colors, card ID). No facts or source IDs changed.
Before/after best-partner content Jaccard is in `SIMILARITY-SAMPLE-FIX.csv`; all 20
remain TEXT_VALID. Examples:

| Card | Before Jaccard | After |
| --- | ---: | ---: |
| STY-0018 | 0.981 | 0.974 |
| STY-0019 | 0.981 | 0.974 |
| STY-0016 | 0.943 | 0.925 |
| STY-0017 | 0.909 | 0.881 |

The fix reduces templated similarity slightly and adds explicit professional
differentiation. It intentionally does not pile synonyms; deeper differentiation
requires card-owner domain review.

## 3. Findings / limits

- Similarity is a review heuristic, not a duplicate verdict.
- Homogeneity remains concentrated in style/material/structure template families;
  not all pairs can be fixed by prompt edits alone.
- No manual/domain/image/visual status is claimed; prompt text only.
