# Public research preview

This repository is a **sanitized public preview**, not the full research vault.

Included:

- 15 selected knowledge cards (structure, material, garment, style, outfit);
- five language READMEs;
- three generated visual plates;
- the `costume-director` skill and a text-only prompt builder;
- a non-commercial research licence.

Intentionally omitted:

- source channels, institutions, URLs and internal source identifiers;
- internal reports, test suites, audit folders and private projects;
- the full 473-card vault and its source ledger.

Status:

- Text and structure checks: established.
- Domain review: not performed for this public preview.
- Real image testing: not performed (no authorised image tool in this environment).
- Human visual approval: not performed.
- GUI UAT: not performed.

The owner authorised this sanitized public release as a research preview. It must
not be described as domain-reviewed, image-tested, human-visual-approved, or
commercially licensed.
