# Costume Director — 项目内技能说明（初始草案）

目的：当用户问“这个角色穿什么 / 如何符合剧本 / 为图像或视频生成服装提示词”时，读取 Vault 数据并提供可解释的 Look 推荐。

工作流程：
1. 从剧本或描述解析角色、剧情日、环境、预算、镜头条件和史实严格度。
2. 使用本地文件搜索或未来 `scripts/query.py` 检索；必须返回实际命中的卡片 ID 和来源链接。
3. 先硬约束再软评分，输出 3 套组合并说明为何选/为何不选。
4. 输出生图 / 视频 Prompt 与锁定项；史实和主观艺术解读严格分开。
5. 知识库空缺时明确说“缺少证据”，提出补库任务，不得捏造馆藏或专家文献。

本文件不是已安装的 DSH 插件。P2 需要按照当前版本 DSH 官方技能集成约定验证与接入。
